📋 Chuẩn Công văn 5512/BGDĐT

Đảm bảo cấu trúc chuẩn gồm 4 hoạt động (Khởi động, Hình thành kiến thức, Luyện tập, Vận dụng) với đầy đủ 4 bước tổ chức giảng dạy.

📐 Công thức Toán học Native (OMML)

Tự động chuyển đổi công thức LaTeX sang định dạng Office MathML (OMML) chuẩn để hiển thị và chỉnh sửa mượt mà trong Microsoft Word & PowerPoint.

📊 Đồ thị & Hình học Tự động

Tích hợp Matplotlib vẽ đồ thị hàm số và minh họa hình học trực quan bám sát nội dung bài giảng.

🔍 Bộ kiểm duyệt (Validator) 5512

Tự động kiểm tra chất lượng giáo án, phát hiện lỗi thiếu bước hoặc thiếu mục tiêu và tự kích hoạt cơ chế sửa lại (Retry Loop).

💡 Hướng dẫn kiểm thử nhanh cho Tester / Developer

  1. Test không tốn token Gemini: Bấm nút Xem trước dữ liệu mẫu (Demo Sample) để lập tức nạp bản giáo án và bộ slide mẫu, kiểm tra giao diện và nút xuất file Word / PPTX.
  2. Test sinh AI thực tế: Chọn một bài mẫu (như Cấp số cộng) và bấm Sinh Kế hoạch bài dạy hoặc Sinh Cả Hai. Quá trình xử lý sẽ hiển thị đồng hồ bấm giờ thời gian thực.
  3. Test xuất file tải về: Chuyển sang tab Giáo án hoặc Slide, bấm nút Tải File Word (.docx) hoặc Tải File PowerPoint (.pptx) để kiểm tra định dạng tài liệu thực tế.
  4. Test chỉnh sửa JSON tùy ý: Vào tab Trình xem / Sửa JSON, bạn có thể sửa trực tiếp nội dung và bấm Xuất file để kiểm tra các trường hợp biên (edge cases).
