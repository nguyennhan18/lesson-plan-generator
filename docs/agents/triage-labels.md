# Triage Labels

When an engineering skill refers to a canonical triage role, use the corresponding exact GitHub label.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | The reporter needs to provide more information. |
| `ready-for-agent` | `ready-for-agent` | The issue is fully specified and ready for an agent to implement. |
| `ready-for-human` | `ready-for-human` | The issue requires human implementation. |
| `wontfix` | `wontfix` | The maintainer has decided against taking action on the issue. |

If the tracker vocabulary changes, update the GitHub label column so skills use the existing labels.
